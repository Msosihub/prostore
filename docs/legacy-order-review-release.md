# Legacy order review queue

`/admin/payments/legacy` is a read-only, derived review queue for recorded-paid orders whose item credits are missing or inconsistent. It requires fresh database-confirmed admin authority, uses parameterized UUID cursor pagination (20 orders/page), and projects only order identifiers and item counts. It includes candidates with no durable payment-attempt record. Existing order detail pages provide the authorized private review context.

This is not a persisted quarantine flag, a settlement verifier or a financial clearance workflow. It never resets paid status, creates attempts, changes stock/balances, sends notifications or calls providers. No dismiss/approve/replay action exists. Current delivery release guards remain active and now also verify the credit belongs to the same order. Missing, misallocated, noncompleted, mismatched or nonfinite credits fail closed. Already-delivered records remain untouched. Unrelated new orders are not globally blocked.

No database migration is added by this change. The full release's prior migration/adoption, provider acceptance, worker, credential handling and backup/restore gates remain. This UI does not resolve existing financial-history discrepancies or make production migration safe by itself. Private operator reconciliation still needs original receipts, inventory evidence, ledger/wallet movements and disputes. No automatic backfill or real transfer is provided.
